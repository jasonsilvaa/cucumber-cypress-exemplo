# 🚀 Quick Start - Comece em 5 Minutos

## 1️⃣ Instale as Dependências
```bash
npm install
```

## 2️⃣ Configure o Ambiente
```bash
cp .env.example .env
# Edite .env com suas credenciais (opcional - já tem valores padrão)
```

## 3️⃣ Execute os Testes
```bash
# Modo headless (rápido)
npm test

# Ou com interface visual
npm run test:open

# Ou com navegador visível
npm run test:headed
```

## 4️⃣ Verifique a Qualidade do Código
```bash
npm run lint        # Verificar
npm run lint:fix    # Corrigir automaticamente
```
